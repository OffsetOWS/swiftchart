# Alert System

## Alert quality

Eligible crypto setups retain their original entry, stop, targets and explicit tracking deadline.

## Telegram flow

Settled TP1, TP2, stop-loss and timed-close events reply to the original alert for recipients who received it. Messages state the event and price. Ambiguous or unresolved events wait for settlement.

## Tracking exit

The trade closes after its 48-hour tracking window if neither the stop nor final target has been reached. The original alert and signal detail show the exact UTC close time.
