# Signal Lifecycle

Saved signals retain their entry, stop, targets and tracking status.

## Signal memory

The original alert identifies the setup and its price levels.

## Outcome checks

Settled target, stop and 48-hour close events use the same tracker as signal history. Unresolved price ordering waits for settlement.

## Tracking window

Crypto positions close at the end of the 48-hour tracking window if neither the stop nor final target has been reached. The exact UTC deadline is shown on the signal.
